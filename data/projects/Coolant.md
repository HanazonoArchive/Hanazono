## Sealed Vault

**What it is?**  
Coolant is a complete operational tool built for an HVAC/R service business. It replaces paper-based workflows with a digital pipeline that mirrors the real-world flow: a customer books an appointment → a quotation is prepared → technicians perform the work and file a service report → a billing statement is issued → payment is collected. Every stage is tracked, printable, and connected to a centralized SQLite database.
